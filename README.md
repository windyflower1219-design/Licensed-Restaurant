# 과제비 식당 체크

회사 근처 식당이 과제비로 써도 되는 **일반음식점**(구청 인허가 기준)인지 지도에서 바로 확인하는 페이지입니다.
데이터는 서울 열린데이터광장 「서울시 강남구 일반음식점 인허가 정보」이고, 필요할 때 버튼 한 번으로 갱신합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 지도 페이지 (Leaflet + OpenStreetMap 배경지도, API 키 불필요) |
| `scripts/fetch_data.py` | CSV 내려받기(실패 시 Open API) → 좌표 변환(EPSG:5174 → WGS84) → `data/restaurants.json` 저장 |
| `data/geocode_cache.json` | 원본에 좌표가 없는 가게를 주소로 찾은 결과(다음 갱신 때 재사용) |
| `.github/workflows/update-data.yml` | 수동 실행(Run workflow) 시 위 스크립트를 돌리고 바뀐 데이터를 커밋 |

```
열린데이터광장 CSV ──(Run workflow, GitHub Actions)──▶ data/restaurants.json ──▶ index.html (GitHub Pages)
```

## 데이터 갱신 (필요할 때만)

자동 예약 실행은 없습니다. 페이지 상단의 **원본 기준일**이 오래됐으면:

1. 페이지 상단 「업데이트」 링크(= 저장소 Actions → 「일반음식점 데이터 갱신」)로 이동
2. **Run workflow** 클릭 (저장소 관리자만 가능, 휴대폰 GitHub 앱에서도 됨)
3. 1~2분 뒤 자동 커밋되고, 다시 1~2분 뒤 페이지에 반영

받는 방법은 위에서부터 시도합니다.

- **CSV 내려받기** (기본): 데이터셋 페이지의 「내려받기(CSV)」 버튼과 같은 요청. 인증키 불필요, 전체 약 5만 건을 5초 안에 받습니다.
- **Open API** (예비): CSV가 실패하면 Secrets의 `SEOUL_API_KEY`로 받습니다. 1,000건씩 여러 번 받아 합쳐서 10분쯤 걸립니다.

원본에 좌표가 없는 영업 중 가게(약 1,200곳)는 OpenStreetMap 주소 검색으로 위치를 찾습니다.

- **건물번호까지 맞은 곳**: 정상 위치로 표시합니다.
- **도로까지만 맞은 곳**: 점선 점으로 "대략 위치"라고 표시합니다.
- **못 찾은 곳**: 제외합니다.

찾은 결과는 `data/geocode_cache.json`에 쌓여 다음 갱신 때는 새 주소만 조회합니다.

직접 내려받은 CSV로 만들 수도 있습니다.

```bash
pip install pyproj
python scripts/fetch_data.py --csv "서울시 강남구 일반음식점 인허가 정보.csv"
```

## 처음 설정

1. 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장
2. (선택) Settings → Secrets and variables → Actions → *Secrets*에 `SEOUL_API_KEY` 등록 (CSV가 막혔을 때 쓰는 예비 경로)
3. Private 저장소의 Pages는 유료 플랜에서만 됩니다. 공공데이터라 Public이어도 문제없고, 인증키는 Secret이라 노출되지 않습니다.

## 회사 위치

`index.html` 상단 `OFFICE_DEFAULT`가 기본값입니다(대화빌딩, 강남구 영동대로96길 20).
페이지의 「회사 위치 바꾸기」 → 지도 클릭으로 각자 바꿀 수 있고, 그 값은 각자 브라우저에 저장됩니다.

## 페이지 기능

- 회사 기준 반경(300m~2km·전체) 안의 일반음식점, 가까운 순 목록. 상호·주소 검색
- 업태 필터(여러 개 동시 선택), 영업상태(영업 중 / 휴업 / 최근 1년 폐업)
- **주점 등 주의업종**: 호프/통닭, 정종/대포집/소주방, 감성주점, 라이브카페
  - 일반음식점이지만 사실상 주점이라 기본으로 숨깁니다. 버튼으로 켜거나 상호를 검색하면 경고와 함께 나옵니다.
  - 대상 업태는 `index.html`의 `CAUTION_TYPES`에서 바꿉니다.
- **같은 건물 여러 곳**: 층만 다른 가게는 점 하나로 묶습니다. 확대하면 개수가 나오고, 누르면 층(B1·1층·2층…) 순서로 모두 보여줍니다.
- **팝업 정보**: 업태, 규모, 전화번호(누르면 전화), 주소·층, 거리·도보 시간
  - 규모 구분: 소형 50㎡ 미만(약 15석 이하) · 중형 150㎡ 미만(15~50석) · 대형 300㎡ 미만(50~100석) · 초대형(100석 이상)
  - 기준: 시설총규모(주방 포함)이고 대략 3㎡당 1석으로 봤습니다. 강남구 분포는 중간값 85㎡, 상위 6%가 300㎡ 이상입니다.
- **리뷰·메뉴·영업시간**: 공공데이터에는 없어서, 가게마다 카카오맵·네이버지도·구글지도로 바로 검색합니다(상호+도로명으로 검색해 다른 지점과 헷갈리지 않게 함).
- 처음 보는 사람용 설명과 범례는 제목 옆 **?** 버튼에 있습니다.

## 알아둘 점

- 지도에 없는 가게는 일반음식점 인허가 목록에 없는 곳입니다(휴게음식점·제과점 등일 수 있음). 같은 건물에 상호가 비슷한 곳이 있을 수 있으니 층·주소까지 확인하세요.
- 새로 받은 건수가 이전보다 30% 이상 줄면(장애로 추정) 덮어쓰지 않고 이전 데이터를 유지합니다.
- CSV 내려받기는 공식 API가 아니라서 사이트가 바뀌면 깨질 수 있습니다. 그때는 Actions 실행 화면에 "Open API로 대신 받습니다"가 찍히고 예비 경로로 넘어갑니다.
